# Week 8 real retrieval migration

## Models

- Embeddings: `BAAI/bge-small-en-v1.5` (384 dimensions)
- Reranking: `BAAI/bge-reranker-base`

Both are configured through the ingestion/evaluation command flags and are
cached by Hugging Face. The model name is part of the embedding cache key.
For a reproducible offline smoke test, `--hash-embeddings` and `--hash` keep
the original deterministic baseline available explicitly.

## Commands

```text
python -m ingest.run
python -m evals.run_retrieval
docker compose -f deploy/docker-compose.pgvector.yml up -d
```

The default ingestion command rebuilds vectors in the real model space. It
does not reuse vectors generated by `hash-v1`.

## Remaining live check

The implementation and Compose configuration are present, but the pgvector
container must be started on a machine with Docker Desktop's Linux engine
running before database connectivity and end-to-end upsert/retrieval can be
verified.
