# Three-minute demo

1. Start the API and show `/v1/health`.
2. Ask a tenant A factoid and point out the SSE final event and indexed chunk citations.
3. Ask for an invented bank requirement; show the refusal with no citations.
4. Repeat the first query as tenant B; show that tenant A citations do not appear.
5. Ask a version-sensitive question and show the newer direction is preferred.
6. Open `evals/results/retrieval.md`, `redteam.md`, and `latency.json` to show the measured artifacts.
